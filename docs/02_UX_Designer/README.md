# 02 — UX Designer

> **Role:** User Experience (UX) Designer  
> **Responsibility:** Human-Computer Interaction (HCI), mental models, cognitive load elimination, and user journeys.  

---

## 🧠 Mental Model & Emotional Journey

| Stage | User Emotional State | UX Goal |
| :--- | :--- | :--- |
| **Morning** | Uncertainty | **Clarity** (Surfaces today's top 3 MITs & Morning Intention) |
| **Afternoon** | Distraction / Fatigue | **Focus** (25-minute Deep Work Timer & Time Blocks) |
| **Evening** | Exhaustion | **Reflection** (Subtle Evening Reflection & Daily Gratitude) |
| **Weekly** | Reactive Planning | **Adjustment** (Automated Sprint Rollover Engine) |

## 🌟 Core UX Rules
- **Maximum 3 Clicks**: Any core action achievable in 3 clicks or fewer.
- **Cognitive Restraint**: Dashboard displays ~6 focused sections, zero clutter.
- **Spotlight Search (`Ctrl+K`)**: Instant keyboard navigation across all 7 destinations.
- **Global Quick Capture (`+`)**: Floating action button persistent across all routes.
