# 06 — Component Library

> **HPS Chapter Reference:** Chapter 9 & 15 — Component Architecture

- `Card` — Standard HPS Charcoal Green `#163526` surface container (`rounded-[18px]`).
- `Button` — Primary Emerald Green `#22C55E` action button (`rounded-[12px]`).
- `MetricCard` — Executive KPI card with trend vector indicators.
- `ScoreRing` — Radial progress score ring.
- `QuickCaptureModal` — Persistent `+` floating action drawer modal.
- `ModalDrawer` — Slide-over drawer container.
