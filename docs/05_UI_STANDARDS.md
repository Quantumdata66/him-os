# 05 — UI Standards

> **HPS Chapter Reference:** Chapter 8 & 15 — UI Standards & Motion Design

- **Restraint**: 75% neutral colors, 20% green shades, 5% feedback accents.
- **Skeleton Loading**: Layout-preserving gradient shimmer skeletons (`.skeleton`) instead of spinning wheels.
- **Micro-Animations**: Fast 150–250ms page transitions and scale hover effects.
