# 03 — UI Designer

> **Role:** User Interface (UI) Designer  
> **Responsibility:** Screen layouts, card design, micro-animations, typography, and visual hierarchy.  

---

## 🎨 Visual Identity Specifications

### Colors
- **Deep Forest**: `#071A12` (Base Canvas)
- **Dark Evergreen**: `#0F2D20` (Elevated Baseline)
- **Charcoal Green**: `#163526` (Card Surfaces)
- **Emerald Slate**: `#1D4735` (Hover Overlay)
- **Emerald Green**: `#22C55E` (Primary Buttons & Selection)
- **Mint Green**: `#4ADE80` (Charts & Score Rings)

### Typography
- **Headings**: `Playfair Display` (Serif, elegant & sophisticated)
- **Body UI**: `Inter` (Clean sans-serif)
- **Telemetry**: `JetBrains Mono` (Crisp monospace)

### Micro-Interactions & Cards
- **Card Radius**: `18px` (`rounded-[18px]`)
- **Button Radius**: `12px` (`rounded-[12px]`)
- **Borders**: `#2B4D3E` 1px subtle borders with hover green glow.
