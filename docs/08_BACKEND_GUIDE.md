# 08 — Backend Guide

> **HPS Chapter Reference:** Chapter 10 — Backend Architecture & Services

- Framework: FastAPI (Python 3.11+) REST Microservices.
- Endpoints:
  - `GET /api/v1/dashboard`
  - `GET /api/v1/analytics`
  - `GET /api/v1/career`
  - `GET /api/v1/projects`
  - `GET /api/v1/goals`
- Security: Row Level Security (RLS) policies & JWT authentication.
