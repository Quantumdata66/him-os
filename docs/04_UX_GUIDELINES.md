# 04 — UX Guidelines

> **HPS Chapter Reference:** Chapter 7 — User Experience & Interaction Design

- **Calm Confidence**: Reduce anxiety and mental clutter.
- **3-Click Rule**: Core actions reached in 3 clicks or fewer.
- **Global Search (`Ctrl+K`)**: Instant Spotlight navigation across all entities.
- **Global Quick Capture (`+`)**: Floating action button persistent on all screens.
