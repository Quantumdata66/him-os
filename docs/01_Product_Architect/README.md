# 01 — Product Architect

> **Role:** Product Architect & Systems Engineering Lead  
> **Responsibility:** High-level system structure, Information Architecture (IA), and domain relationship modeling.  

---

## 🏛️ Information Architecture (IA)

```
HIM OS 7 Canonical Life Destinations
├── 🏠 HOME (/dashboard & /) —— Daily Command Center ("What deserves attention right now?")
├── 📅 TODAY (/today) —— Execution Only (Morning planning, MITs, time blocks, reflection)
├── 🛠️ BUILD (/build) —— Everything Created (Projects, Career Engine, Portfolio, Repos)
├── 🎓 LEARN (/learn) —— Learning Ecosystem (Books, Courses, German Goethe B1 Anki, Papers)
├── 📈 GROW (/grow) —— Life Growth Measurement (Finance, Net Worth, Ventures, FX Hedging, Tax)
├── 🧠 THINK (/think) —— Second Brain (Workspace Studio, Knowledge Graph, Decisions, Notes)
└── 🔄 REVIEW (/review) —— Reflection Rituals (Daily/Weekly reviews, Rollover, Achievements)
```

## 📐 System Principles
1. **Life Before Features**: Expose life domains, not CRUD endpoints.
2. **One Home for Everything**: Single source of truth for every domain record.
3. **Progressive Disclosure**: High-level clarity first; details revealed on intentional inspection.
