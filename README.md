# Project HIM OS — Personal Operating System

> **"Prototype today. Legacy tomorrow."**  
> *A unified executive operating system built around human behavior, disciplined execution, and continuous compounding.*

---

## 🌟 Executive Overview
**HIM OS** is not a planner, habit tracker, or note-taking clone. It is a **Personal Operating System** — a centralized command center to organize, execute, monitor, improve, and compound every important area of life.

Built according to the 272-page **HIM OS Product Specification (HPS)**, HIM OS transforms scattered intentions into disciplined execution while eliminating cognitive load through progressive disclosure.

---

## 🏛️ The 7 Canonical Life Destinations

```
HIM OS Canonical Navigation Tree
├── 🏠 HOME (/dashboard) —— Daily Command Center ("What deserves my attention right now?")
├── 📅 TODAY (/today) —— Execution Only (Morning planning, MITs, time blocks, reflection)
├── 🛠️ BUILD (/build) —— Everything Created (Projects, Career Engine, Portfolio, Repos)
├── 🎓 LEARN (/learn) —— Learning Ecosystem (Books, Courses, German Goethe B1 Anki, Papers)
├── 📈 GROW (/grow) —— Life Growth Measurement (Finance, Net Worth, Ventures, FX Hedging, Tax)
├── 🧠 THINK (/think) —— Second Brain (Workspace Studio, Knowledge Graph, Decisions, Notes)
└── 🔄 REVIEW (/review) —— Reflection Rituals (Daily/Weekly reviews, Rollover, Achievements)
```

---

## ⚡ Tech Stack
- **Frontend**: Next.js 15.5.21 (React 19), TypeScript 5.x, Tailwind CSS v4, Lucide React
- **Backend Services**: FastAPI (Python 3.11+), Supabase PostgreSQL, Row Level Security (RLS)
- **Deployment**: Vercel Edge Network (`main` branch auto-deploy)

---

## 🚀 Quick Start

```bash
# 1. Clone Repository
git clone https://github.com/Quantumdata66/him-os.git
cd him-os

# 2. Install Dependencies
npm install

# 3. Launch Local Development Server
npm run dev

# 4. Open in Browser
open http://localhost:3000
```
